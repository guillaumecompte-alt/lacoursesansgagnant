# La course sans gagnant

Animation pour un cours de mathématiques sur la vitesse et la proportionnalité :
les 3 voiturettes doivent franchir la ligne d'arrivée **en même temps**.

- **Jeu 1** : toutes les voiturettes partent de la ligne de départ, on règle un délai pour chacune.
- **Jeu 2** : aucun délai, on règle la position de départ de chaque voiturette.

## Utilisation

Tout tient dans un seul fichier, `index.html` (HTML, CSS et JavaScript, sans dépendance ni compilation).
Il suffit de l'ouvrir dans un navigateur.

Version en ligne : https://guillaumecompte-alt.github.io/lacoursesansgagnant/

## Modifier les voiturettes

Les vitesses (en cm/s) et la tolérance d'arrivée simultanée (0,2 s) se règlent
en haut du script, dans `index.html` (tableau `CARS` et constante `TOLERANCE`).
